# 세계 상황판 (World Situation Board)

OSINT 기반 지정학 상황판의 소스입니다. 게시본: https://claude.ai/artifact/VdTv11W2Zv8j55Rpf4aBGJ

## 구성
- `app.html` — 페이지 템플릿(스타일·마크업·앱 로직). `/*__WORLD__*/`, `/*__DATA__*/`, `/*__THEATERS__*/`, `/*__IW__*/` 자리에 데이터가 삽입됩니다.
- `world.json` — 세계 지도 TopoJSON (Natural Earth 10m을 면적 임계 1e-4로 단순화, 약 2.4MB). 정지 상태에서 그립니다.
- `world110.json` — 110m TopoJSON. 회전·확대 중과 클릭 판정에 씁니다.
- `labels_en.js` — 지도 라벨용 영어 표기(전역·해협·도시·기지·시설·부대). 지도는 영어, 패널은 한국어.
- `intel.js` — 수집 에이전트 산출: 해협 9곳 물동량·운임·보험료, 전쟁 경제 6개 분야, 강대국 경쟁 7개 축. 모든 수치에 날짜·출처 URL.
- `data_snapshot.json` — 스냅숏 데이터: 해협, 항로, 시장, 도시, 사건(출처 URL 포함).
- `theaters.js` — 전역(theater) 브리핑 16건.
- `iw.js` — 징후·경보(I&W) 프레임: 종합 경보단계, BLUF 핵심판단·신뢰도, 72시간 변화, 감시 항목, 수집 공백, 전역별 판단·징후 지표·시나리오·행위자·정보 공백, 군사태세(기지·시설·송유관·부대), 전역 간 연계, 한국 영향.
- `build.py` — 위 파일을 하나의 `index.html`로 합칩니다.

## 지도 엔진 (2차)
정사영 지구본입니다. 드래그는 쿼터니언 트랙볼이라 어느 방향으로든 극을 넘어 굴러가고, 북쪽 위로 버튼이 기울기(감마)를 되돌립니다. 휠·핀치로 확대합니다. 육지는 캔버스에 그리며 회전 중에는 110m, 멈추면 10m 단순화본을 그립니다. 항로·송유관·측정선은 별도 캔버스, 마커·라벨은 SVG 오버레이이고 지구 뒷면은 숨깁니다.

## 빌드
```
python3 dashboard/build.py   # dashboard/index.html 생성
```

## 분석 관례
- 신뢰도: 높음/보통/낮음 (ICD 203 준용). 확률대는 ICD 203 척도 표현.
- 출처 등급: Admiralty 코드(신뢰성 A~F, 신빙성 1~6). 매체 유형 기준 자동 1차 등급.
- 징후 지표 상태: obs(관측) / part(부분·미확인) / no(미관측).
- 부대 위치는 보도 시점 광역 추정(C3~C4)이며 갱신 대상입니다.

## 자동 수집 (3차)
`pipeline/`이 6시간마다 GitHub Actions에서 돌아 `data_snapshot.json`(사건)과 `intel.auto.json`(시세·PortWatch·PLA·수집원 상태·변화)을 갱신하고, `build.py`가 이를 `index.html`에 주입합니다. 트립와이어는 Issue로, 일일 SITREP은 Release로 나갑니다. 자세한 내용은 [`pipeline/README.md`](pipeline/README.md)와 루트 README의 운영 표를 보세요.

## 상품·거래 보드 (4차)
`commodities.js`(34개 품목 레지스트리, 분쟁→상품 전이 행렬, 자원 허브)와 `intel.js`의 `INTEL.cm`(에너지·농산물·거시 조사)이 **상품** 탭과 **일정** 탭을 채웁니다. 타일 호가는 라벨 정규식과 점수(선물·현물·월물 라벨 우선, 재고·생산·포지션 라벨 감점)로 고릅니다.

## 시나리오·백테스트 (5차)
- `scenario.js` — 시나리오 템플릿 18개. 전역(th)·기본 확률·지평·상품별 조건부 충격(평균·표준편차)·한국 영향·감시 지표·트립와이어·과거 사례 id. 같은 전역은 상호배타, 전역 간 독립으로 몬테카를로(3,000회) 추출하고 기저 잡음은 연율 변동성×√(지평/252)로 넣습니다. **시나리오** 탭에서 확률·강도를 조정하고 Markdown 복사, GitHub Issue 제출, 분석관(Claude) 전달이 됩니다. 설정은 브라우저에 저장됩니다.
- `analogs.js` — 과거 사례(이벤트 스터디) 라이브러리. 사건 전일 대비 +1/+5/+20/+60일 변동률, 출처 URL. **백테스트** 탭에서 자산·범주별로 보고 선택 시나리오의 사례가 강조됩니다.
- `data/judgments.json` — 판단 장부. 상황판의 핵심판단·전역 판단·시장 판단 67건을 확률(ICD 203 용어 → 중앙값)과 기한으로 등록. 백테스트 탭에서 적중/빗나감을 판정하면 Brier 점수와 보정(calibration) 막대가 즉시 갱신되고, "Issue로 제출"로 저장소에 기록합니다.
- `data/backtest.json`, `data/series.json` — 주간 워크플로가 2년 일봉을 받아 (1) 고경보 전역의 타격·해상 사건 이후 실측 변동, (2) 트립와이어 임계치 돌파 이력과 그 뒤 60일 수익률, (3) 장부 통계를 계산합니다. 상황판은 있으면 표시하고 없으면 안내만 둡니다.
- `analyst.js` — 위 세 기능의 UI. `build.py`가 `/*__ANALYST__*/`에 주입합니다.

## 일일 동기화·예측 적중 추적 (5차)
- `data/house_view.json` — 분석관 하우스 뷰(시나리오 id·확률·강도). 시나리오 탭 "하우스 뷰" 버튼으로 불러오고, 시나리오 Issue에서 "하우스 뷰로 채택"을 체크하면 봇이 갱신합니다.
- `pipeline/forecast.py` — `run.py forecast`가 하우스 뷰를 몬테카를로(20,000회, 날짜 시드)로 돌려 `data/forecasts/<날짜>.json`에 자산별 기대 변동·P5/P25/P50/P75/P95·상승 확률과 과거 사례 기준값을 저장합니다. `run.py score`가 `data/series.json`으로 20거래일 뒤 실제 변동을 대조해 `data/scorecard.json`을 만듭니다: 방향 적중률, 90%·50% 구간 포함률, PIT 히스토그램(분포 보정), MAE와 무변동·과거 사례 기준 대비 스킬, 자산별·예측일별 집계, 진행 중 예측의 경과, 판단 장부 Brier 추이.
- 상황판 **백테스트** 탭 맨 위 "예측 적중 추적"이 이를 표시합니다. GitHub Pages 판은 매일 갱신되고 "지금 동기화" 버튼으로 최신 채점을 다시 불러옵니다. 아티팩트 판은 재게시 시점의 채점을 보여줍니다.

## 6차: 에이전트·동기화·가설·포지션
- **내비게이션** 상황·시장·분석·운영 4그룹으로 탭을 묶고, `Ctrl/⌘+K` 전역 검색(사건·지표·판단·시나리오·과거 사례·일정·수집원·가설)을 넣었습니다.
- **저장소 동기화 (`live.js`)** 아티팩트는 외부 fetch가 막혀 있지만 `mcp` 캐퍼빌리티로 보는 사람의 GitHub 커넥터를 통해 `data/*.json`을 읽습니다. 헤더의 "저장소 동기화"를 누르면 시세·사건·트립와이어·RFI·채점·장부·하우스 뷰를 갱신하고 패널을 다시 그립니다. 한 번 성공하면 다음 열 때 자동 동기화합니다. 커넥터가 없거나 권한이 없으면 원인별 안내를 띄웁니다.
- **에이전트 분석관 (`agent.js`)** 분석관 탭의 "에이전트 실행"은 `sample` 캐퍼빌리티의 도구 호출로 Claude가 페이지 함수를 직접 부릅니다. 조사 도구(사건 검색, 호가·지표, 시나리오 시뮬레이션, 과거 사례, 채점표, ACH, 위험도, 일정)와 행동 도구(시나리오 뷰 변경, 판단 초안, 탭 열기)가 있고, 행동 기록과 초안(Issue 링크)이 아래에 쌓입니다. 프리셋: 비대칭 기회, 하우스 뷰 재검토, 판단 장부 정리, 위험 경고 초안, 촉매 지도.
- **ACH 경쟁가설분석 (`ach.js`)** 호르무즈·흑해·연준·엘니뇨·대만 5개 질문. 증거마다 등급 가중 일치도를 두고 불일치 점수가 낮은 가설이 생존합니다. 비진단적 증거와 '빼면 1위가 바뀌는' 민감 증거를 표시하고, 셀을 눌러 판정을 바꿀 수 있습니다(브라우저 저장).
- **파이프라인 에이전트 (`pipeline/advisor.py`)** Anthropic SDK 도구 실행기(`client.beta.messages.tool_runner`)로 Claude가 저장소 데이터를 도구로 조회한 뒤 하우스 뷰 재조정·새 판단·경고 전역·판정 제안을 JSON으로 내고, 워크플로가 Issue로 올립니다.

## 경제 위험도 (6차 보강)
- **종합 경제 위험 지수 0~100** (`risk.js`, `pipeline/risk.py`). 하우스 뷰 몬테카를로(30일 고정 지평)로 한국 수입 바스켓(원유 30%, LNG 12%, 석유제품 8%, 운임 13%, 곡물 14%, 금속 10%, 비료 3%, 환율 5%)의 P95 충격을 구한 '시나리오 꼬리' 30%, VIX·DXY·10년물·브렌트·원/달러의 '시장 스트레스' 25%, 해협 상태·운임의 '공급망 스트레스' 20%, 매니지드머니 순포지션의 '포지셔닝 과밀' 10%, 고경보 전역 타격·해상 사건의 '사건 밀도' 10%, 채점표 구간 포함률의 '모델 불확실성' 5%의 가중 합입니다. 35/55/75에서 보통·높음·심각.
- **상품별 위험 등급 R1~R5**: 분포 폭(P5~P95)·변동성·분쟁 전파 가중·7일 사건 밀도. 상품 타일에 배지로 붙고 위험도 탭에서 표로 봅니다.
- **운영**: 일일 동기화가 `data/risk.json`·`risk_history.json`·배지를 쓰고, SITREP에 한 줄, 트립와이어 `econ_risk_70`(70 이상이면 Issue), 에이전트 도구 `get_risk`와 프리셋 "위험 헤지 설계"가 붙습니다. 브리프 상단에 게이지가 뜹니다.

## 7차: 정보부 운영 계층 (`ops.js`, `pipeline/products.py`)
정보순환(요구 → 수집 → 처리·분석 → 생산 → 배포 → 피드백)을 저장소 위에 올렸습니다. 운영 그룹에 탭 세 개가 늘었습니다.
- **당직** 현재 교대(주간 08~20 / 야간 20~08 KST), 당직 분석관, 미결 과업(열린 RFI·판정 기한 경과·EEI 공백·발동 트립와이어·이견), 전역별 경보단계(WATCHCON)와 7일 변경 이력, 인수인계 일지. "인수인계 작성"은 미결 과업을 채운 Issue 양식을 열고, 에이전트 프리셋 "교대 브리핑 작성"이 초안을 씁니다.
- **요구** 우선정보요구(PIR) 8건과 핵심정보요소(EEI). 각 EEI에 징후·수집원·상태(답변중/충족/공백)·최근 답변일이 붙고, 수집원 레지스트리의 지역·태그로 수집 계획(매칭 수집원)을 자동으로 보여줍니다. 공백은 RFI로 발행합니다.
- **생산물** 일련번호가 붙은 완성 생산물 목록(DIB·WR)과 ICD 203 분석 기준, 이견 채널 기록. 생산물은 `products/`에 Markdown으로 보존됩니다.
- **브리프**에 운영 현황(교대·경보 변경·EEI 공백·72시간 경고 보고)이, 에이전트에 `get_ops` 도구와 "PIR 공백 점검"·"경보단계 재평가" 프리셋이 추가됐습니다.
- 페이퍼 북(가상 포지션) 기능은 제거했습니다. 경제 위험 지수는 한국 수입 바스켓 기준으로 유지합니다.

## 보건안보 전역 (7차 보강)
이르쿠츠크 항페스트연구소 사망 사건이 상황판에 없던 것은 수집 규칙(페스트·검역·실험실 사고 키워드 부재)과 전역 부재 때문이었습니다. `bio` 전역(시베리아 페스트·보건안보)을 신설해 사건 12건·판단·징후·시나리오·행위자·공백, PIR-9, ACH 질문, 경보단계 3, 시나리오 템플릿 `bio_spread`, 판단 장부 2건을 넣었고, 수집 규칙(H 유형·bio 전역 정규식·관련도 키워드), 지명사전(이르쿠츠크·셸레호프·울란우데·호브드 등), 수집원(Google News 감염병·한국어 페스트, CIDRAP, UKHSA 주간 감시), 트립와이어 `bio_health_events`를 추가했습니다. 한국어 Google News는 `lang: ko`로 수집합니다.
