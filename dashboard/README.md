# 세계 상황판 (World Situation Board)

OSINT 기반 지정학 상황판의 소스입니다. 게시본: https://claude.ai/artifact/VdTv11W2Zv8j55Rpf4aBGJ

## 구성
- `app.html` — 페이지 템플릿(스타일·마크업·앱 로직). `/*__WORLD__*/`, `/*__DATA__*/`, `/*__THEATERS__*/`, `/*__IW__*/` 자리에 데이터가 삽입됩니다.
- `world.json` — 세계 지도 TopoJSON (Natural Earth 10m을 면적 임계 1e-4로 단순화, 약 2.4MB). 정지 상태에서 그립니다.
- `world110.json` — 110m TopoJSON. 회전·확대 중과 클릭 판정에 씁니다.
- `labels_en.js` — 지도 라벨용 영어 표기(전역·해협·도시·기지·시설·부대). 지도는 영어, 패널은 한국어.
- `intel.js` — 수집 에이전트 산출: 해협 9곳 물동량·운임·보험료, 전쟁 경제 6개 분야, 강대국 경쟁 7개 축. 모든 수치에 날짜·출처 URL.
- `data_snapshot.json` — 스냅숏 데이터: 해협, 항로, 시장, 도시, 사건(출처 URL 포함).
- `theaters.js` — 전역(theater) 브리핑 16건.
- `iw.js` — 징후·경보(I&W) 프레임: 종합 경보단계, BLUF 핵심판단·신뢰도, 72시간 변화, 감시 항목, 수집 공백, 전역별 판단·징후 지표·시나리오·행위자·정보 공백, 군사태세(기지·시설·송유관·부대), 전역 간 연계, 한국 영향.
- `build.py` — 위 파일을 하나의 `index.html`로 합칩니다.

## 지도 엔진 (2차)
정사영 지구본입니다. 드래그는 쿼터니언 트랙볼이라 어느 방향으로든 극을 넘어 굴러가고, 북쪽 위로 버튼이 기울기(감마)를 되돌립니다. 휠·핀치로 확대합니다. 육지는 캔버스에 그리며 회전 중에는 110m, 멈추면 10m 단순화본을 그립니다. 항로·송유관·측정선은 별도 캔버스, 마커·라벨은 SVG 오버레이이고 지구 뒷면은 숨깁니다.

## 빌드
```
python3 dashboard/build.py   # dashboard/index.html 생성
```

## 분석 관례
- 신뢰도: 높음/보통/낮음 (ICD 203 준용). 확률대는 ICD 203 척도 표현.
- 출처 등급: Admiralty 코드(신뢰성 A~F, 신빙성 1~6). 매체 유형 기준 자동 1차 등급.
- 징후 지표 상태: obs(관측) / part(부분·미확인) / no(미관측).
- 부대 위치는 보도 시점 광역 추정(C3~C4)이며 갱신 대상입니다.

## 자동 수집 (3차)
`pipeline/`이 6시간마다 GitHub Actions에서 돌아 `data_snapshot.json`(사건)과 `intel.auto.json`(시세·PortWatch·PLA·수집원 상태·변화)을 갱신하고, `build.py`가 이를 `index.html`에 주입합니다. 트립와이어는 Issue로, 일일 SITREP은 Release로 나갑니다. 자세한 내용은 [`pipeline/README.md`](pipeline/README.md)와 루트 README의 운영 표를 보세요.

## 상품·거래 보드 (4차)
`commodities.js`(34개 품목 레지스트리, 분쟁→상품 전이 행렬, 자원 허브)와 `intel.js`의 `INTEL.cm`(에너지·농산물·거시 조사)이 **상품** 탭과 **일정** 탭을 채웁니다. 타일 호가는 라벨 정규식과 점수(선물·현물·월물 라벨 우선, 재고·생산·포지션 라벨 감점)로 고릅니다.

## 시나리오·백테스트 (5차)
- `scenario.js` — 시나리오 템플릿 18개. 전역(th)·기본 확률·지평·상품별 조건부 충격(평균·표준편차)·한국 영향·감시 지표·트립와이어·과거 사례 id. 같은 전역은 상호배타, 전역 간 독립으로 몬테카를로(3,000회) 추출하고 기저 잡음은 연율 변동성×√(지평/252)로 넣습니다. **시나리오** 탭에서 확률·강도를 조정하고 Markdown 복사, GitHub Issue 제출, 분석관(Claude) 전달이 됩니다. 설정은 브라우저에 저장됩니다.
- `analogs.js` — 과거 사례(이벤트 스터디) 라이브러리. 사건 전일 대비 +1/+5/+20/+60일 변동률, 출처 URL. **백테스트** 탭에서 자산·범주별로 보고 선택 시나리오의 사례가 강조됩니다.
- `data/judgments.json` — 판단 장부. 상황판의 핵심판단·전역 판단·시장 판단 67건을 확률(ICD 203 용어 → 중앙값)과 기한으로 등록. 백테스트 탭에서 적중/빗나감을 판정하면 Brier 점수와 보정(calibration) 막대가 즉시 갱신되고, "Issue로 제출"로 저장소에 기록합니다.
- `data/backtest.json`, `data/series.json` — 주간 워크플로가 2년 일봉을 받아 (1) 고경보 전역의 타격·해상 사건 이후 실측 변동, (2) 트립와이어 임계치 돌파 이력과 그 뒤 60일 수익률, (3) 장부 통계를 계산합니다. 상황판은 있으면 표시하고 없으면 안내만 둡니다.
- `analyst.js` — 위 세 기능의 UI. `build.py`가 `/*__ANALYST__*/`에 주입합니다.
